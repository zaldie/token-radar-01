How implied value is computed

implied = round( TVL × 0.25 × growth × maturity × reach )

Base multiple
0.25 × TVL
Growth
7d change clamped to −60% … +60%; down weeks weigh 0.50, up weeks 0.40
Maturity
0.6 + 0.4 × (1 − e−age/365); unknown age counts as 180 days
Reach
1 + 0.02 per extra chain, up to 5 extra chains (max 1.10)

One function scores every row; no protocol name is special-cased. A hot week is noisy, so gains are damped harder than losses, and a single +4,448% week can add at most +24%. The detail panel below recomputes each row from the same formula, so the page and the board always agree.
